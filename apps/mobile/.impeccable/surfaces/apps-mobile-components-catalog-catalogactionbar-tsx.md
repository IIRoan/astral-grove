# Catalog action bar

## Scope / mode

Operate — search catalog chrome on phone and web.

## Direction

Phone: leading All/Owned + Simple add, trailing segmented list/grid + icon-only sort/filter. Natural widths, 44pt targets, no stretched equal slots, no sort short-label text. Desktop keeps labeled sort/filters.

## Memorable moment

Prefs on the left, refine tools on the right — one glance, thumb-reachable.

## Constraints

Preserve simple-add behavior, filter sheet, and sort sheet. Do not invent a second filter entry point.
